# BriVillage — глэмпинг-курорт в Казани

[![GitHub Pages](https://img.shields.io/badge/demo-online-brightgreen)](https://v1nstery.github.io/houses/)
[![HTML](https://img.shields.io/badge/HTML-90.5%25-orange)](https://github.com/V1nStery/houses)
[![SCSS](https://img.shields.io/badge/SCSS-6.6%25-pink)](https://github.com/V1nStery/houses)

**BriVillage** — это адаптивный лендинг для глэмпинг-курорта, расположенного в экологически чистом районе недалеко от Казани. Проект включает описание домиков, услуг, цен, отзывов гостей, а также интерактивную карту с выделенной территорией села Бритвино.

🔗 **Демо**: [https://v1nstery.github.io/houses/](https://v1nstery.github.io/houses/)

---

## 📌 Особенности проекта

- **Адаптивная вёрстка** — корректно отображается на всех устройствах (десктоп, планшеты, мобильные).
- **Сборка через Gulp** — автоматизация задач (компиляция SCSS, минификация, оптимизация изображений, запуск сервера).
- **Кастомные SVG-маркеры** на Яндекс.Карте с выделенной территорией села.
- **Swiper-слайдеры** для отзывов, услуг и галереи.
- **Аккордеон** с плавной анимацией высоты и появлением контента.
- **LazyLoad** карты при скролле.
- **CSS-переменные**, семантическая вёрстка, доступность.

## 🚀 Запуск проекта локально

1. **Клонировать репозиторий**  
   ```bash
   git clone https://github.com/V1nStery/houses.git
   cd houses

Установить зависимости

bash
npm install
Запустить режим разработки (с автообновлением)

bash
gulp
— откроется локальный сервер с livereload.

Собрать продакшен-версию (папка dist)

bash
gulp build
